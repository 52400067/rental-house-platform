# Lỗ hổng bảo mật Web (Attacks and Countermeasures)

• Đặc tả: Nghiên cứu về an toàn thông tin cơ bản trên môi trường web.

• Yêu cầu tiểu luận: Khảo sát các hình thức tấn công XSS, SQL injection, CSRF.
Trình bày biện pháp phòng ngừa (Input validation, escaping, security headers).

• Yêu cầu Demo: Xây dựng ứng dụng web cố tình để lộ lỗ hổng, thực hiện mô
phỏng tấn công, sau đó trình bày giải pháp code để vá lỗi.
